# LineReservationBot（公式LINE 問い合わせ・予約自動応答ボット）

## 概要
友人が運営するソフトテニススクールのWebサイトと連動する、公式LINEの自動応答ボットです。
元々はメールでの問い合わせ形式だったものを、普段使い慣れたLINEのトーク画面上で対話しながら入力できるようにすることで、スマホから手軽に申し込みができる仕組みを目指して開発しています。

## 作ったきっかけ
Webサイト制作などをしている親友から「公式LINEの自動応答Botを作ってみないか」と誘われたのが始まりです。
もともとJavaでゲームなどが作れることに興味があったこともあり、生成AIに教えてもらいながらコードの意味や配列などを少しずつ理解する勉強も兼ねて、一人で開発に挑戦しています。
覚えることは多いものの作ること自体が苦ではなく、仕組みが動く楽しさやエラーを解消できたときの嬉しさを実感したことで、「実際の開発現場で本格的に学びたい」と強く思うようになりました。

## 使用技術
* **言語:** Java
* **フレームワーク / ビルドツール:** Spring Boot / Maven
* **API連携:** LINE Messaging API
* **その他:** HTML / CSS / JavaScript / Git / GitHub

## 主な機能（現在の実装状況）
* **LINEからのメッセージ受信・自動返信**
  * LINE Messaging API（Webhook）を通じてユーザーが送信したメッセージを受け取り、特定のキーワード（「予約」など）に対して自動応答メッセージを返す処理を実装しています。
* **入力エラー時の制御**
  * 想定外の入力があった際にもエラーでシステムが止まらないよう制御を入れています。

## 工夫した点
* **使いやすさの意識**
  * 元々はお問い合わせメール形式だったものを、スマホのトーク画面で違和感なくやり取りできるよう構成を調整しました。
* **地道な改善**
  * エラーが出たときは原因を1つずつ調べながら修正を繰り返し、少しずつ機能を追加しています。

## 今後やりたいこと（こんな機能を作りたい！）
現在は「予約」と送信すると自動返信が返ってくる段階ですが、現場でしっかり技術を学びながら、まずはテニススクール向けに以下の機能を追加していきたいと考えています。

* **1. 対話形式での予約・問い合わせ完了フロー（計9項目の自動ヒアリング）**
  * Webサイトのフォームにある9項目（名前・フリガナ・連絡先・学年・年齢・テニス経験・希望クラス・問い合わせ内容）を、一問一答形式で順番に聞き取り、最後に入力内容の確認画面を出してそのまま申し込み完了できる仕組みにしたいです。
* **2. Googleカレンダーとの自動連携（空き枠確認・スケジュール登録）**
  * 希望日時を選んだ際に、Googleカレンダーと連携して「空き状況の自動チェック」や「予定の自動登録」ができるようにしたいです。
* **3. 運営側（管理者）への即時通知＆データ管理**
  * 問い合わせ・予約が入った瞬間に、管理者用LINEやメールへ内容を自動通知したり、データベース（SQL）に情報を保存して後から一覧で確認できるようにしたいです。
* **4. ボタン選択やリマインド通知の追加**
  * 文字を打つ手間を減らすためにLINEのボタン選択機能を取り入れたり、前日に自動でリマインド通知を送る機能も実装してみたいです。

### 将来的な展望：他の業種・親戚の仕事への応用
現在はソフトテニススクール向けに開発していますが、「LINEで手軽に問い合わせや予約を受け付ける仕組み」は他の仕事にも幅広く応用できると感じています。
今後さらに開発スキルを磨き、**設定項目（質問内容や業種ごとのメニュー）を柔軟に切り替えられる汎用的な設計**に発展させることで、親戚が営んでいる仕事のお問い合わせ対応など、身近な人の業務効率化にも役立てていくことが目標です。
